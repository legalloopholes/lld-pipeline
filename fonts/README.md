Free (SIL Open Font License) stand-ins for the Mac fonts, from github.com/google/fonts:
- M PLUS Rounded 1c ExtraBold  -> used where the Mac uses Arial Rounded MT Bold (captions, cards, handle)
- Archivo Black                -> Arial Black (3D signs)
- Gelasio                      -> Georgia (3D documents)
Licenses: OFL.txt in each folder (M PLUS Rounded 1c is listed as OFL in Google Fonts' METADATA).
